# STAAD.Pro run and XtraReport steps - CDSCO 45 kWp ballast frame

Model: `CDSCO_45kW_Ballast_Frame.std` (ONE frame; a table = 2 identical frames). Units in file: METER for coordinates, then MMS/NEWTON.
Generated by `calc/staad_gen.py` from the same engine as the Excel workbook; the file text was re-parsed and solved independently and matches the workbook to 5.5e-8.

## 1  Run
1. Open the .std in STAAD.Pro (check the title bar shows this file). File > Save once.
2. Analyze > Run Analysis. Expect 0 errors. (No `SET NL` warning applies; the model is linear.)
3. Compare with `expected_results.csv` (per combination, units N / mm):
   reactions FY at nodes 2-5 (J1-J4), FX at node 2, axial of member 6 (A-B), vertical displacement at nodes 1 (A) and 6 (C) for combos 17-18.
   STAAD prints axial force +ve = compression and reaction FY up = +ve. Paste the values into Excel sheet **STAAD_Map** (yellow cells): differences must be < 1 %.

## 2  What is (and is not) in the model
- Nodes 1-10 = A, J1-J4, C, B, S1, M, S2. Members 1-5 base (prismatic, I = I_eff), 6 vertical (TRUSS), 7-10 inclined (member 10 released MZ at C).
- Supports: node 2 (J1) FX FY FZ MX MY; nodes 3-5 FY FZ MX MY. Out-of-plane loads are zero (plane model).
- Load cases 1 DL (joint loads + base UDL, self-weight lumped so it matches the workbook), 2 WL uplift, 3 WL down, 4 EQ +X. Combinations 11-18 = C1-C6, S1, S2 (IS 800 Table 4; S = unfactored service).
- Sections are PRISMATIC (A, J, I_eff) so STAAD's IS 800 code check cannot be used; member checks are done in the workbook (sheet Members) with the unsymmetric-bending modulus. If the client insists on a STAAD code check,
  replace the property line by the catalogue section ISA 50x50x5 and set BETA per the legs - the forces do not change.
- `JOB NAME` is a placeholder (`ENG TBD`): insert the ENG number of the issuing company before exporting the report.

## 3  XtraReport (client-format evidence - must come from STAAD itself)
Reports > Report Setup, item order: Job Information - Sections - Materials - Basic Load Cases - Combination Load Cases - pictures - Beam End Forces - Reaction Summary - Node Displacement Summary.
Suggested pictures (caption): Whole Structure | 3D Rendered View | Section labels (zoom on the frame) | DL | WL Up | WL Down | EQ +X | Bending Moment Mz, combo 12 | Support reactions, combo 12.
Traps that cost time on earlier jobs:
- Pictures do not appear in Report Builder until you Save the model and then Regenerate.
- Selecting a load case silently fails: confirm the case name in the status bar before each capture.
- Reports > Configure > Header: untick *License information* or the licence banner prints on every page.
- Section-label picture: zoom on the single frame; at whole-structure extent the labels overprint.
Then: Templates > Save (once per company), Export to PDF.
